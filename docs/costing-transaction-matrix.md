# Costing transaction matrix

Financial methods supported in V2 (`StockCostState`, `StockValuationFact`, `StockFifoLayer`, `ItemStandardCostRevision`):
- **Moving weighted average (`WAC`)**, **First-In First-Out (`FIFO`)**, and **Standard Cost (`STANDARD`)** at `CompanyCode + BranchCode + ItemCode`.
- Physical allocation remains at `CompanyCode + BranchCode + ItemCode + Warehouse + Location + Lot + Status + BaseUom` (`IvBalLoc`).
- `StockValuationFact` (together with `StockFifoLayer` / `StockFifoLayerConsumption`, `PurchaseReceiptCostSettlement` / `PurchaseCostAdjustment`, `ProductionCostRestatementFact`, `SalesReturnCostAllocation`, and `StockCountCostBasis` / `StockCountReplayGeneration`) is the historical monetary authority; `IvBalLoc` prices remain operational cache/display fields only.
- All V2 postings run under a single branch-locked `StockPostingContext` (`STOCK_LEDGER_V2_POSTING_ID`). Normal postings seal via `CompleteInTransactionAsync`; open-period historical replay postings (gated by `OpenPeriodBackdatedReplayEnabled`, default OFF) validate all required active valuation generations and seal via `CompleteReplayInTransactionAsync`, recording foreign-owned corrections in `StockReplayRun` and `StockReplayEffect`.
- See `plans/productionv2_backdated_replay_impact_manifest.md` for the detailed route-by-route replay coverage matrix, supported bounded shapes, and explicit fail-closed blockers.

## Mandatory invariants

- `BaseQty` and `CostAmount` are positive magnitudes; `Direction` is `+1` or `-1` (value-only adjustments have `BaseQty == 0`).
- Fact identity is `StockPostingId + PostingLineNo + SplitOrdinal`.
- Inventory history/balance/lot foreign keys remain `int`; posting, replay, count-basis/generation, and production identities remain `long`.
- Canonical replay chronology key is `(EffectiveAt, ClassPriority, OriginalPostingSequence, LineIdentity, AttachedSuborder)`, where `ClassPriority = 0` for ordinary events and `1` for end-of-day Stock Count resets (`CountDate.Date.AddDays(1).AddTicks(-1)`), and corrections inherit their business owner's original key and sequence.
- Reversal facts copy the active generation's exact amount and link `ReversesValuationFactId`; a complete replacement generation is appended only after exact reversal of all active splits/consumptions.
- Unsupported backdated dependency shapes, negative intermediate physical slices, QA hold violations, cost-method cutovers inside an open replay tail, missing cost authority, or physical/value/WIP/settlement/COGS mismatches fail closed and roll back the entire root transaction.
- `StockPeriodSnapshot*` remains quantity-only. `StockValuationPeriodSnapshot*` is the independent financial close; FIFO receipt reversals are excluded from active issue-consumption completeness checks, and older-period correction facts written by later roots are included in snapshot watermarks.
